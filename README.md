# 🌰 Acorn-Flute (도토리 피리) — Smart Band Accompaniment & Sync Machine

> **Teensy 4.0** 기반의 실시간 템포·다이나믹 추종 합주 파트너 & 빈티지 MP3 감성 로컬 오디오 플레이어

---

## 1. 프로젝트 개요 (Overview)
**Acorn-Flute**는 건반(피아노) 연주자가 없는 밴드 합주 및 라이브 환경에서 연주자의 **실시간 템포(BPM)**와 **연주 강약(Dynamics)**에 반응하여 반주 트랙을 동기화하거나 알고리즘 반주를 생성해 주는 데스크톱형 스마트 오르골 머신입니다.

* **핵심 철학:** 악기 원음(Dry Signal)의 100% 보존 (`0ms` 아날로그 직결) + 직관적인 빈티지 픽셀 UI
* **배치 형태:** 앰프 상단이나 보면대 위에 거치하여 손으로 조작하는 데스크톱 폼팩터

## 4. 핵심 소프트웨어 아키텍처 (Firmware)

### 🎛️ 듀얼 동작 모드
* **Mode A (Track Sync):** MicroSD에 저장된 WAV 반주 음원을 재생하며, 연주자의 템포와 강약에 맞춰 실시간 타임 스트레칭(`Granular / WSOLA`) 및 볼륨 추종 수행.
* **Mode B (Algo Jam):** 외부 음원 없이 입력되는 베이스 근음(Root)과 스케일을 실시간 추출하여 경량 화성학 알고리즘 기반의 피아노/패드 백킹을 즉석 생성.

### 🎯 실전 합주 동기화 알고리즘
1. **적응형 템포 추적 (`±12%` 유효 윈도우):**
   * 베이스 어택(Onset) 간격을 분석하되, 8/16비트 속주나 싱코페이션(당김음, `±25~50%` 변동)으로 인한 오작동을 걸러내기 위해 직전 템포 대비 **`±12%` 이내의 변동만 유효한 템포 변화**로 인정합니다.
   * 인정된 변화량은 관성 필터(Slew Rate Limit)를 거쳐 2~3박자에 걸쳐 자연스럽게 반주 속도에 반영됩니다.
2. **다이나믹 볼륨 추종 (Envelope Follower):**
   * `AudioAnalyzeRMS` 블록으로 연주 에너지를 측정, 마디 단위 평균 세기에 비례해 반주 음량을 `65% ~ 100%` 사이에서 유기적으로 조절합니다.
3. **OS 제어판 30배 소프트웨어 게인 부스트 (`[INPUT: BASS / MIC]`):**
   * 별도의 하드웨어 토글 스위치 없이 UI 설정 메뉴에서 입력 모드를 전환합니다.
   * `MIC` 모드 활성화 시 SGTL5000 내장 프리앰프(`micGain`) 및 DSP 입력 게인을 **30배(+30dB)** 증폭하고 노이즈 게이트 임계값을 자동 상향하여, 추후 드럼 스네어 핀마이크 연결 시에도 타격 피크를 정확히 포착합니다.

## 5. 빈티지 MP3 UI & 물리 조작계

```text
+--------------------------------------------------+
| [MODE A]  IN:BASS   124 BPM               [VOL]  |
|--------------------------------------------------|
|                                                  |
|                  A m 7                           |
|            ▁ ▃ ▅ █ ▆ ▄ ▂ ▁                       |
|                                                  |
| ▶ 01_Forest_Piano_Backing.wav   [██████░░░░]     |
+--------------------------------------------------+
```

* **우측 클릭 노브 (Master Encoder):**
  * **회전:** 곡 리스트 탐색 / 메뉴 커서 이동
  * **짧게 클릭:** 재생 · 일시정지 / 메뉴 항목 선택
  * **길게 클릭 (1.5초):** 이전 화면으로 돌아가기 / `Mode A ↔ Mode B` 전환
* **좌측 클릭 노브 (Volume & Panic Reset):**
  * **회전:** `(3)`, `(4)`, `(5)` 통합 반주 마스터 볼륨 조절 (ADC 소프트웨어 제어)
  * **길게 클릭 (1.5초):** **긴급 템포 리셋 (Tempo Reset)** — 합주 중 박자가 크게 어긋났을 때 초기 기준 BPM 및 마디 시작으로 즉시 복귀
