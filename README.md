# 🌰 Acorn-Flute (도토리 피리) — Smart Band Accompaniment & Sync Machine v2.0

## 1. 프로젝트 개요
- **목적:** Teensy 4.0 기반의 밴드 합주용 실시간 템포 동기화 백킹트랙 플레이어 및 AI 즉흥 잼 세션 머신[cite: 6]
- **폼팩터:** 합주실 바닥 및 데스크톱 겸용 고내구성 하드웨어 인클로저 (레트로 게임보이 + 이펙터 하이브리드 디자인)[cite: 6]
- **부팅 속도:** 약 0.5초 이내 (초고속 콜드 부팅 및 즉각 연주 대기)[cite: 6]

## 2. 하드웨어 및 오디오 I/O 아키텍처
### 2.1 핵심 프로세싱 및 저장장치
- **MCU:** Teensy 4.0 (ARM Cortex-M7 @ 600MHz)[cite: 6]
- **Audio Codec:** SGTL5000 Audio Shield[cite: 6]
- **스토리지:** 내부 봉인형 MicroSD 카드 (십자드라이버 하우징 고정, 외부 탈착 불가 구조로 진동 및 분실 방지)[cite: 6]
- **USB 연결 (원케이블 인터페이스):** USB-C 포트 1개로 아래 3가지 기능 동시 수행[cite: 6]
  1. **전원 공급:** 페달보드 파워 서플라이 `5V 1A` 구동 (별도 전원 스위치 및 배터리 배제)[cite: 6]
  2. **파일 전송 (`MTP Disk`):** PC 탐색기에서 SD카드 내 WAV 트랙 직접 드래그 앤 드롭 관리[cite: 6]
  3. **실시간 디버깅 (`Serial`):** 연주 중 입력 피크(`[PEAK]`), PLL 템포 오차(`[PLL_BPM]`), 버튼 상태(`[STATE]`) 실시간 모니터링[cite: 6]

### 2.2 상단 패널 오디오/제어 포트 (총 7개)
1. **`[0]` USB-C:** 5V 1A 전원 입력 + MTP 파일 전송 + Serial 디버깅 겸용[cite: 6]
2. **`[1]` 6.35mm 모노 IN:** 악기(베이스/기타/마이크) 오디오 입력[cite: 6]
3. **`[2]` 6.35mm 모노 DRY OUT:** 입력된 악기 원음 바이패스 직결 출력[cite: 6]
4. **`[3]` 6.35mm 스테레오(TRS) FOOTSWITCH IN:** 외부 2버튼 풋스위치 연동 (RockBoard MOD 1 V2 패치베이 호환, 모노/스테레오 풋스위치 예외 처리 내장)[cite: 6]
5. **`[4]` 6.35mm 스테레오 LINE OUT:** 반주(MR / 잼 세션) 스테레오 라인 출력[cite: 6]
6. **`[5]` XLR PA OUT:** 공연장 및 합주실 믹서 직결용 밸런스드 출력[cite: 6]
7. **`[6]` 3.5mm 스테레오 AUX (PHONE OUT):** 개인 모니터링용 이어폰/헤드폰 출력[cite: 6]

## 4. 물리 조작계 및 인클로저 설계 (v2.0 확정 사양)
### 4.1 본체 상판 조작부 (게임보이 DMG 레트로 아키텍처)
- **부품 구성:** 오리지널 게임보이(`For GB`) 규격 6버튼 확장 카본 접점 PCB + 실리콘 러버돔 + 십자키 & A/B 버튼 (전원 슬라이더 캡 미사용, `X/Y/L/R` 접점은 향후 단축키 확장용 예비 확보)[cite: 6]
- **내구성 구조:** 십자키 중앙 반구형 피벗 기둥이 하중을 흡수하고, 실리콘 러버돔이 기판 접점을 완전히 밀폐하는 방진 구조 채택 (후면 스페이서 지지대로 기판 밀착 고정)[cite: 6]
- **버튼 매핑:**
  - **십자키 (상/하/좌/우):** 파일 탐색기 폴더 및 곡 목록 스크롤 전용[cite: 6]
  - **A 버튼:** 선택 / 하위 폴더 진입 / 옵션 토글[cite: 6]
  - **B 버튼:** 취소 / 상위 폴더 복귀[cite: 6]

### 4.2 풋스위치 조작부 (본체 & 외부 병렬 연동)
- **본체 풋스위치 2개:** **2핀 SPST 모멘터리(비고정형/복귀형) 무소음 소프트 터치 풋스위치** 채용 (3PDT 래칭 사용 불가)[cite: 6]
- **배선 구조:** 본체 풋스위치 2개(L/R)와 상단 `6.35mm TRS 풋스위치 포트(Tip/Ring)`를 하드웨어 병렬 연결하여 동일한 신호로 처리[cite: 6]
- **L / R 스위치 통합 제어 로직:**

| 스위치 | 짧은 누름 (Tap, `< 0.3s`) | 길게 누름 (Hold, `≥ 0.8s`) |
| :--- | :--- | :--- |
| **L 스위치** | **이전 곡 (Prev)** *(정지 상태에서만 작동)*[cite: 6] | **스탠바이(Standby) 진입 & 악기 입력 속박자(BPM) 카운팅 → 발을 떼는 순간(Release) 칼박자 출발(Play / 원샷 발사)**[cite: 6] |
| **R 스위치** | **다음 곡 (Next)** *(정지 상태에서만 작동)*[cite: 6] | **즉시 정지 (Stop)**[cite: 6] |

- **오작동 방지 안전장치 (Playback Lock):** 트랙이 **재생(`PLAY`) 중일 때는 L/R 스위치의 짧은 누름(Prev/Next)을 전면 차단(Lock)**하며, 오직 **R 스위치 길게 누름(Stop)**만 활성화됨.[cite: 6]

### 4.3 측면 마스터 볼륨 노브 (안테나 스타일)
- **부품 구성:** 페달용 가변저항(Alpha 포텐셔미터) + 금속/플라스틱 노브를 케이스 측면에 너트로 강건하게 체결 (외관상 안테나 포인트 디자인)[cite: 6]
- **내구성 보강:** 발밑 충격으로 인한 축 파손 방지를 위해 케이스 모서리에 보호 가드 턱 설계[cite: 6]
- **제어 방식:** Teensy 아날로그 핀(`A0`)으로 전압을 읽어 소프트웨어 스무딩 필터 적용 후 OS 단계 디지털 마스터 볼륨 제어[cite: 6]

## 5. 디스플레이 & UI/UX 시스템
- **디스플레이:** 3.12인치 단색 OLED (SSD1322 컨트롤러, `256×64` 해상도, 그린/옐로우 자발광, 빈티지 CLI 터미널 UI)[cite: 6]
- **작동 모드 구성:**

  2. **`[J 모드]` REALTIME JAM:** 실시간 AI 잼 세션 출석부 (`DRUM`, `BASS`, `PIANO/EP`, `PAD` 개별 ON/OFF 토글) 및 사용자 연주 코드·BPM 기반 즉흥 반주 생성[cite: 6]

## 6. 오디오 DSP 및 동기화 알고리즘
- **마이크/악기 입력 프리앰프(소프트웨어 단):** 제어판 설정을 통한 **최대 30배 디지털 증폭** 및 자동 노이즈 게이트 적용[cite: 6]
- **실시간 BPM 추적 (PLL & Standby Counting):**
  - `L 스위치 Hold` 스탠바이 구간 동안 유입되는 악기 어택(Peak) 간격을 실시간 분석하여 초기 BPM과 위상(Phase)을 잠금[cite: 6]
  - 스위치 `Release` 즉시 계산된 템포와 정박에 맞춰 오디오 스트림 트리거 및 재생 중 미세 템포 변화 추적[cite: 6]
